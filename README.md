# Controle de Investimentos — Planilha em Excel

Projeto educacional de organização e acompanhamento de investimentos pessoais por meio de uma planilha. A proposta é centralizar informações financeiras e facilitar a consulta de aportes, valores investidos e evolução patrimonial ao longo do tempo.

## Objetivo

Aplicar conceitos de organização de dados financeiros em uma ferramenta simples e adaptável para controle pessoal de investimentos.

## Funcionalidades descritas no projeto

- Registro de aportes e valores investidos.
- Acompanhamento da evolução financeira.
- Organização dos investimentos em um único arquivo.
- Estrutura editável para adaptação às necessidades de cada pessoa.

> As funcionalidades acima foram descritas no README original e ainda precisam ser verificadas diretamente na planilha.

## Tecnologia

- Microsoft Excel (`.xlsx`).

## Como utilizar

1. Baixe o arquivo [`Controle de Investimentos.xlsx`](Controle%20de%20Investimentos.xlsx) disponível neste repositório.
2. Abra a planilha no Microsoft Excel.
3. Examine os campos disponíveis e preencha as informações referentes aos seus investimentos.
4. Consulte os registros para acompanhar seus aportes e sua evolução financeira.

> Outros editores de planilhas podem apresentar diferenças de compatibilidade. Faça uma cópia do arquivo antes de alterar fórmulas ou estruturas existentes.
